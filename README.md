# Пример проекта: «Аптека» (PostgreSQL + ASP.NET Core)

Образец для рубежного контроля. Сдавать и защищать его нельзя: у вас своя тема.

## Запуск

1. pgAdmin: подключиться к базе `postgres`, выполнить `sql/01_create_db.sql`.
2. Открыть Query Tool на базе `pharmacy` и по очереди выполнить `02`, `03`, `04`, `05`, `06`, `08`, `09`.
   Скрипты `07` (транзакции) и `10` (сценарии показа) выполняются по шагам вручную.
3. В `api/appsettings.json` вписать пароль пользователя postgres.
4. `cd api` → `dotnet run` (или F5 в Visual Studio). Сайт: адрес из консоли, Swagger: `/swagger`.

## Структура

- `sql/` — скрипты базы данных по номерам (01–10)
- `api/` — Web API на C# (Program.cs) и сайт (`wwwroot/index.html`)

Подробная инструкция: `Руководство_с_примерами.docx`.
